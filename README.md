# Starfall

A Space Invaders-style arcade game built with HTML, CSS, and vanilla JavaScript.

Open dist/index.html in your browser to play locally. No installation or build step is required.

- Move: Left/Right arrows or A/D
- Fire: hold Space
- Pause/resume: P
- Start/restart: Enter or the on-screen button
- Mobile: use the touch buttons
- Sound: toggle at the top right

Clear each wave to face faster enemies and restore one shield. Destructible cover blocks shots from both sides. Your personal best is saved in this browser.

Files: dist/index.html (page), dist/style.css (appearance), dist/game.js (game logic).
